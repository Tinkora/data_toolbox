## [0.1.0-alpha.1] - 2026-08-14

### Added

- Published the bounded CSV/TSV inspector for native CLI and browser-local WASM workflows.
- Added deterministic CSV, TSV, and JSON exports with explicit spreadsheet formula policies.
- Added four-platform CLI release archives, checksums, SPDX SBOM, license evidence, and provenance.
- Added strict local CSV/TSV inspection through Rust core, native CLI, and WASM browser UI.
- Added bounded resource limits, stable diagnostics, bilingual documentation, and local-only privacy guarantees.
