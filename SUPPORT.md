# Support

This is a local utility, not a hosted data-processing service. For a reproducible bug, open a GitHub issue with the smallest non-sensitive input, the exact command or browser steps, tool versions, operating system, and observed versus expected behavior.

Do not post secrets, private CSV contents, credentials, or vulnerability details. Use [SECURITY.md](SECURITY.md) for security reports. Questions about new formats, network access, persistence, or agent transports belong in a discussion first so the user value and trust boundary can be reviewed.
